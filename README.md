# Rocket® COBOL Fundamentals

Rocket® COBOL Fundamentals is a free, instructor-led video course in the COBOL programming language. The course teaches the fundamentals of the COBOL language, introduces the Rocket® COBOL syntax, and usage of Rocket® COBOL tools.

The sample programs available here are for use with the [Learn COBOL](https://marketplace.visualstudio.com/items?itemName=RocketSoftware.rocket-learncobol) extension for Visual Studio Code.

For full details about the course visit [cobol.com](https://www.cobol.com).
